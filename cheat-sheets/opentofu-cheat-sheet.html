OpenTofu language cheat sheet

OpenTofu is an open-source infrastructure-as-code tool, a Linux Foundation fork of Terraform: you describe resources in HCL files and it creates and keeps them in sync through providers. Docs; current for v1.13 (Sep 2026).

HCL: Syntax, Types, Expressions

OpenTofu uses HCL, HashiCorp’s configuration language designed for Terraform. OpenTofu’s style conventions.

Syntax

How a file is written.

Blocks

The unit of configuration: a file holds only blocks, and blocks nest.

Schema
block_type "identifier"* {

A block declares one thing — a resource, a variable…; the labels name it, and the type fixes how many there are.

identifier*: any

An argument (also called an attribute) gives a named key its value. Keys within a block are unique and unordered.

block_type* "identifier"* { … }

A nested block holds settings that come in groups; each block type lists which it accepts.

}

Example
variable "env" {
  type    = string
  default = "dev"
}

Function Calls

Built-in Call

identifier(any*) -> any
length(var.names)

Call a built-in by its bare name; arguments by position, never by name.

Provider-defined Call

provider::name::identifier(any*) -> any
provider::aws::arn_parse(var.arn)

Call a function a provider ships (1.7+); an alias goes between the names.

Argument Expansion

identifier(list...) -> any
max(var.nums...)

Spread a list into separate arguments.

Comments

Comments

# …   // …   /* … */
# TODO: tighten the policy

Notes the parser ignores; # is the idiom, fmt rewrites // to it.

Type Constraints

HCL’s types, and how to combine them.

Primitives

string
"af-${var.env}"  42  true

Text, in "" only; ${} interpolates.

number
42  3.5  1e6  "42"

Integers and floats as one type; numeric strings convert.

bool
true  false  "true"  "false"

true or false, also as strings; 1/0 don’t convert.

Collections

With the structural types below, what a collection can be.

list(TYPE)
["a", "b"]

An ordered sequence, indexed by position; duplicates allowed.

set(TYPE)
toset(["a", "b"])

Unordered, unique, no literal form. A list converts to one where a set is expected — except in for_each.

map(TYPE)
{ acme = 7, "2024-q1" = 3 }

Values looked up by string key; quote keys that aren’t identifiers.

Structural

Fixed shape, each slot its own type; also a collection.

object({ name*: TYPE })
{ name = "x", size = 3 }

Named fields, each its own type. A { k = v } literal is an object until converted to a map.

tuple([TYPE*])
["x", 3, true]

Positional, each its own type. A [a, b] literal is a tuple until converted to a list. Rarely written.

optional(TYPE, any?)
object({
  ttl = optional(number, 60)
})

An object field the caller may omit; the default is used instead.

Special

any
type = any

Accept any type; it is inferred from the value.

null
default = null

No value: leave the provider’s default in place.

Expressions

How values are written and combined. References are listed with the block they point to.

Strings and Templates

Interpolation

"…${any}…" -> string
"af-${var.env}-reports"

Embed a value in a string.

Directives

"…%{ if bool }…%{ endif }…"
"…%{ for x in collection }…%{ endfor }…" -> string
"Hi%{ if var.x != "" } ${var.x}%{ endif }"

Branch or loop inside a string.

Heredoc Strings

<<-EOT
…
EOT -> string
user_data = <<-EOT
  echo hi
EOT

A multi-line string; - strips the indent; ${} works inside.

Escape Sequences

\n  \"  \\  \t  $${  %%{
"Cost: $${${var.n}}"

Escapes; $${ and %%{ write a literal ${ / %{.

Conditional Expressions

Conditional

bool ? any : any -> any
var.env == "prod" ? 3 : 1

Choose between two values; both arms must share a type.

For Expressions

Walk a collection; the result converts to list or map where one is expected.

Tuple Result

[ for k?, v in collection : any if? bool ] -> tuple
[ for p in var.partners : upper(p) ]

Build a tuple by transforming each element; one name = value, two = key then value.

Object Result

{ for k?, v in collection : any => any if? bool } -> object
{ for k, v in var.m : k => v.arn if v.ok }

Build an object the same way; ... after the value groups duplicate keys.

Dynamic Blocks

Repeat a nested block from a collection, inside any body that takes nested blocks: resource, data, provider, provisioner.

Schema
dynamic "block_type" {

Generate copies of the nested block type named by the label.

for_each: any

One copy of the block per element.

iterator?: name

Name for the current element; defaults to the label.

content { … }

The body of each copy; use iterator.key / .value.

}

Example
dynamic "ingress" {
  for_each = var.cidrs
  content {
    cidr_blocks = [ingress.value]
  }
}

Splat Expressions

Splat

list[*].attr -> tuple
aws_x.y[*].arn

Collect one attribute from every element of a list.

Operators

Comparison

== != < <= > >= -> bool
var.env == "prod"

Compare two values; == is deep on collections.

Logical

&& || ! -> bool
var.a && !var.b

And, or, not.

Arithmetic

+ - * / % -> number
(var.n + 1) % 2

Arithmetic; unary - too.

Index and Attribute Access

any[number]   any[string]   any.attr -> any
var.cidrs[0]  var.m["k"]  var.obj.name

Pick an element by position, key or attribute name.

OpenTofu: Block Types

OpenTofu is an infrastructure-as-code tool forked from Terraform. These are its block types; providers define the rest.

Language and Compatibility Settings

language is tofu-native (1.12+); terraform keeps Terraform compatibility.

language Block

Version and edition (1.12+); keep in .tofu.

Schema
language {

Declares what this module needs from OpenTofu (1.12+).

compatible_with? {

Which implementation, at which versions, this module is written for.

opentofu: string

The version constraint OpenTofu must satisfy.

}

edition?: tofu2024

The language edition; leave unset — the default is the only one.

experiments?: [identifier*]

Opt in to named experimental features; warns on every run.

}

Example
language {
  compatible_with { opentofu = ">= 1.12" }
}

terraform Block

Terraform-compatible settings.

Schema
terraform {

Settings for the whole module: providers, state, compatibility.

required_version?: string

OpenTofu versions this module works with; prefer language on 1.12+.

required_providers? {

The providers this module uses, and where to get them.

name*: {

The provider’s local name — used by provider blocks and as the prefix of its resource types.

source: string

Registry address, namespace/name.

version?: string

Which versions of the provider this module accepts.

configuration_aliases?: [name.alias*]

Aliased configurations a child module expects its caller to pass via providers.

}

}

backend? "backend" { … }

Where state lives — s3, gcs, http…; a local file if omitted. Arguments may use var./local. (1.8+).

cloud? { … }

Terraform Cloud settings. Rare with tofu.

encryption? { … }

Encrypt state and plan files client-side (tofu-only).

provider_meta? "name" { … }

Module metadata for a provider. Rare.

}

Example
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
  backend "s3" {
    bucket       = "af-tofu-state"
    key          = "hub.tfstate"
    use_lockfile = true
  }
}

Version Constraints

The string required_version, provider version and module version take.

"= 1.2.0"   "!= 1.2.0"
version = "= 5.31.0"

Exactly this version; or anything but.

">= 1.2"  "> 1.2"  "<= 1.2"  "< 1.2"
required_version = ">= 1.12, < 2.0"

Bounds; combine with a comma.

"~> 1.2"
version = "~> 5.0"

Pessimistic: at least this, same leading digit — ~> 1.2 allows 1.x ≥ 1.2, ~> 1.2.0 only 1.2.x.

Providers

Plugins, one per platform. Declared in required_providers.

Provider Configuration

Configure a provider; repeat with alias.

Types
provider_arguments
region = "us-west-2"

Arguments and nested blocks a provider defines; see its docs.

Schema
provider "name" {

Configures one provider — credentials, region; the label is its local name from required_providers.

alias?: string

A second configuration of the same provider; resources choose it with provider.

for_each?: map | set

One configuration per key (1.9+); needs alias.

provider_arguments*

The provider’s own settings: region, credentials…

}

Example
provider "aws" {
  region = "us-west-2"
}
provider "aws" {
  alias  = "partner"
  region = "us-east-1"
  assume_role { role_arn = "arn:…" }
}
# use: provider = aws.partner

Resources

Things to create and manage.

Resource Blocks

One infrastructure object; many with for_each.

Types
resource_type
aws_s3_bucket  cloudflare_record  # provider_type

Prefix with the provider (aws_), then a type it supports. Set the provider meta-argument to use an aliased provider’s configuration.

Schema
resource "resource_type" "name" {

Manages one infrastructure object: the provider’s type, then your handle for it.

meta_arguments*

How many instances, in what order, with which provider.

provider_arguments*

The object’s settings, as the provider defines them.

lifecycle? { … }

How changes to this object are handled.

provisioner* "type" { … }
connection? { … }

Scripts run on the object at create or destroy. Last resort.

}

References
resource_type.name.attr

Read one attribute; without attr, the whole object.

resource_type.name[any]

One instance of a for_each or count block, by key or index.

Example
resource "aws_s3_bucket" "reports" {
  for_each = var.partners
  bucket   = "af-reports-${each.key}"
}
# use: aws_s3_bucket.reports["acme"].arn

Provisioners

Scripts on create or destroy. Last resort.

Schema
provisioner "type" {

Runs a script when the object is created, or destroyed; the type is local-exec, remote-exec or file.

when?: destroy

Run on destroy instead of create.

on_failure?: continue | fail

What a failing script does; the default fail taints the object.

name*: any

The type’s own settings: command, inline, source…

}

Example
provisioner "local-exec" {
  command = "./notify.sh"
}

Connection Settings

connection { … }
connection {
  type = "ssh"
  host = self.public_ip
}

How to reach the machine over ssh (winrm removed in 1.13); may use self.

Data Sources

Read-only lookups of things that already exist.

data Block

Same labels as resource.

Schema
data "resource_type" "name" {

Reads an existing object from the provider; nothing is created.

meta_arguments*

lifecycle takes only conditions.

provider_arguments*

How to find it; its attributes are the answer.

}

References
data.resource_type.name.attr

Read a field of the looked-up object.

Example
data "aws_vpc" "main" {
  id = "vpc-0a1b"
}
# use: data.aws_vpc.main.cidr_block

Ephemerality

Values that never reach state or plan (1.11+). Also write-only attributes.

Ephemeral Resources

Opened each run, closed at the end.

Schema
ephemeral "resource_type" "name" {

Opens a short-lived value each run — a credential, a tunnel — and never stores it.

meta_arguments*

Plus pre- and postconditions.

provider_arguments*

How to obtain it, per type.

}

References
ephemeral.resource_type.name.attr

Read it, only where an ephemeral value is allowed.

Example
ephemeral "random_password" "db" {
  length = 24
}
# use: ephemeral.random_password.db.result

Meta-Arguments

Keys OpenTofu adds to every resource, data, ephemeral, module. Write them first.

count, for_each, depends_on, provider

count, for_each, enabled are exclusive.

meta_arguments
for_each = var.partners

The four below — count | for_each, depends_on, provider — allowed in every resource, data, ephemeral, module.

for_each?: map | object | set

Create one instance per key of a map or set; lists refused — toset().

each.key

The current key.

each.value

The current value.

for_each = var.partners
bucket   = "af-${each.key}"
count?: number

Create N instances by index; removing one shifts the rest.

count.index

The current index.

count = length(var.names)
name  = var.names[count.index]
depends_on?: [resource_type.name*]
depends_on = [aws_iam_role.fn]

Force an ordering no reference implies; whole blocks only.

provider?: name.alias
provider = aws.partner

Which configuration of the provider: by local name and alias; unaliased if omitted. Modules use providers.

lifecycle Blocks

For resource; data, ephemeral, module: subsets.

Schema
lifecycle {

How changes to the enclosing block are handled.

enabled?: bool

Turn the block on or off (1.11+) without count and [0] indexing.

prevent_destroy?: bool

Make any plan that would delete it fail.

destroy?: true | false

false: on removal, forget it instead of destroying it. Literal only.

create_before_destroy?: bool

Build the replacement before removing the old one.

ignore_changes?: [attr*] | all

Accept drift on these attributes after creation.

replace_triggered_by?: [any*]

Replace this object when a referenced one changes.

precondition* {

An assumption checked at plan time.

condition: bool

Must be true; may use self.

error_message: string

Shown when it isn’t.

}

postcondition* { … }

The same, checked after apply.

}

References
self.attr

The current object, in conditions and provisioners.

Example
lifecycle {
  enabled         = var.is_prod
  prevent_destroy = var.is_prod
  ignore_changes  = [tags["Scan"]]
  postcondition {
    condition     = self.arn != null
    error_message = "no arn"
  }
}

Variables and Outputs

A module’s inputs, outputs and locals.

Input Variables

Set by -var, *.tfvars, TF_VAR_x or caller.

Schema
variable "name" {

Declares an input the caller sets; the label is its name.

type?: TYPE

What values are accepted; defaults to any, but declare it.

default?: any

The value when the caller sets none; omit to require one. Literal only.

description?: string

What it is for; shown in docs and errors.

sensitive?: bool

Redact it from plan output; still stored in state.

nullable?: bool

false rejects an explicit null.

ephemeral?: bool

Never written to state or plan (1.11+).

deprecated?: string

Warn callers that this is going away; the message says what to use instead (1.10+).

validation* {

A rule the value must pass at plan; may reference the variable.

condition: bool

Must be true.

error_message: string

Shown when it isn’t.

}

}

References
var.name

Read its value, anywhere in the module.

Example
variable "env" {
  type    = string
  default = "dev"
  validation {
    condition     = contains(["dev", "prod"], var.env)
    error_message = "dev or prod"
  }
}
# use: var.env

Output Values

The module’s exposed values.

Schema
output "name" {

Exposes a value to the caller, or prints it after apply; the label is its name.

value: any

The value exposed.

description?: string

What it is; shown in docs.

sensitive?: bool

Redact it from output; required if the value is sensitive.

ephemeral?: bool

Required if the value is ephemeral (1.11+).

deprecated?: string

Warn callers that this is going away; the message says what to use instead (1.10+).

depends_on?: [resource_type.name*]

Force an ordering; rarely needed on outputs.

precondition* { … }

A check before the value is exposed; same shape as in lifecycle.

}

Example
output "reports_arn" {
  value = aws_s3_bucket.reports.arn
}

Local Values

Named values, module-scoped.

Schema
locals {

Names values for reuse within this module; several blocks merge.

name*: any

A named expression, computed once.

}

References
local.name

Read it; singular local.

Example
locals {
  prefix = "af-${var.env}"
  tags   = { Project = "impact-hub" }
}
# use: local.prefix

Modules

A directory of config, called as a unit.

Module Blocks

One call. Ref outputs as module.name.out.

Schema
module "name" {

Calls a module — a directory of configuration — under your handle.

source: string

Where the module comes from: a path, registry address or git URL. May use var./local. (1.8+).

version?: string

Which versions are accepted; registry sources only.

providers?: {

Pass provider configurations down to the child.

name*: name.alias

The child’s provider name = this module’s name.alias.

}

meta_arguments*

lifecycle takes only enabled.

name*: any

Values for the child’s input variables.

}

References
module.name.output

Read one of the child’s outputs.

module.name[any]

One instance, with for_each or count.

Example
module "reports" {
  source    = "./modules/partner-bucket"
  for_each  = var.partners
  providers = { aws = aws.partner }
  partner   = each.key
}
# use: module.reports["acme"].bucket_arn

Checks

Assertions on live infrastructure; failures warn.

check Block

Schema
check "identifier" {

Asserts something about live infrastructure on every plan; failures warn, never block.

data? "resource_type" "name" { … }

A lookup scoped to this check; its errors only warn.

assert+ {

A condition to evaluate; at least one.

condition: bool

Must be true.

error_message: string

Shown when it isn’t.

}

}

Example
check "site_up" {
  data "http" "home" { url = "https://…" }
  assert {
    condition     = data.http.home.status_code == 200
    error_message = "site down"
  }
}

Import and Refactoring

State changes as code: apply, then delete the block.

import Block

Adopt an existing object into a resource.

Schema
import {

Adopts an existing object into state, under a resource you have written.

to: resource_type.name

The resource address that will own it.

id: string

The provider-side identifier; its format depends on the type.

for_each?: map | set

Import many; use each in to and id.

provider?: name.alias

The aliased configuration, if the resource uses one.

}

Example
import {
  to = aws_s3_bucket.reports
  id = "af-reports"
}

moved Block

Rename or move without destroying.

Schema
moved {

Renames or moves a resource or module in state without recreating it.

from: resource_type.name

Old address; also module.x or one instance.

to: resource_type.name

New address, same kind.

}

Example
moved {
  from = aws_s3_bucket.bucket
  to   = aws_s3_bucket.reports
}

Removing Resources

Stop managing, with or without destroying.

Schema
removed {

Stops managing an object you have deleted from the configuration.

from: resource_type.name

Address of a block deleted from config.

lifecycle? {

What happens to the real object.

destroy: true | false

false keeps it and just forgets it.

}

provisioner* "type" { when: destroy … }

Destroy-time scripts for the removed object.

}

Example
removed {
  from = aws_s3_bucket.legacy
  lifecycle { destroy = false }
}

Files, Command Line, Tests

A working directory, the commands that act on it, and how to test it.

Files and Directories

A module is a directory; everything in it is read together.

Configuration Files

*.tf  *.tofu
versions.tofu  # versions.tf ignored

The configuration. All files merge; .tofu beats a same-named .tf (1.8+), so put tofu-only syntax there.

*_override.tf
main_override.tf

Merged last, overriding same-named blocks; for local patches to code you don’t own.

*.tf.json  *.tofu.json
{ "variable": { "env": { "type": "string" } } }

The same configuration in JSON, for generated code.

*.tfvars  *.auto.tfvars
tofu plan -var-file=prod.tfvars

Values for input variables, per environment; .auto.tfvars loads without a flag.

Generated Files

.terraform.lock.hcl
git add .terraform.lock.hcl

Pins provider versions and hashes so every run resolves the same; commit it.

.terraform/  terraform.tfstate
echo ".terraform/" >> .gitignore

Downloaded providers and modules; local state. Gitignore both.

Paths

Where things are, for file() and friends.

path.module
"${path.module}/policy.json"

This module’s directory.

path.root
"${path.root}/env.tfvars"

The root module’s directory.

path.cwd
path.cwd

The directory tofu was run from.

terraform.workspace
terraform.workspace == "prod"

Current workspace name.

Command Line

The commands that act on a working directory.

Everyday

tofu init [-upgrade]
tofu init -upgrade

Set up the directory: download providers and modules, connect the backend.

tofu plan [-out=file] [-refresh-only]
tofu plan -out=tf.plan

Show what would change; -refresh-only shows drift alone.

tofu apply [file] [-auto-approve]
tofu apply tf.plan

Make the changes — from a saved plan, or plan and apply in one step.

tofu fmt [-recursive]  tofu validate
tofu fmt -recursive && tofu validate

Rewrite to canonical style; check syntax and references offline.

tofu destroy
tofu destroy -target=module.scratch

Plan and apply the removal of everything in state.

Inspect

tofu state list | show resource_type.name | mv | rm
tofu state show aws_s3_bucket.reports

Read or edit state by hand; prefer moved/removed blocks.

tofu console
> cidrhost("10.0.0.0/8", 5)

A REPL for expressions against your config and state.

tofu output [-json] [name]
tofu output -raw reports_arn

Print output values after apply.

tofu show [plan] [-json]
tofu show -json tf.plan

Print a saved plan, or the state, for humans or machines.

Tests

Assert what a plan or apply produces, from *.tftest.hcl or *.tofutest.hcl files next to the module or in tests/.

Test Files

Top-level blocks of a test file.

variables? { identifier*: any }
variables { env = "test" }

Input values for every run, unless a run overrides them.

provider* "name" { … }
provider "aws" { region = "us-west-2" }

A real provider configuration for the tests to use.

mock_provider* "name" { … }
mock_provider "aws" {}

A fake provider, so plan-only tests need no credentials (1.8+).

tofu test [-filter=file] [-verbose]
tofu test -filter=tests/basic.tftest.hcl

Run the test files in order; each run destroys what it applied.

run Block

One test case; runs sequentially, and may read earlier runs’ outputs as run.name.output.

Schema
run "name" {

Names the case in the report.

command?: plan | apply

What to execute before asserting; apply by default.

variables? { identifier*: any }

Inputs for this run only; override the file’s.

assert* {

A condition the result must satisfy; a failed one fails the run.

condition: bool

May reference resources, outputs and variables of the module.

error_message: string

Shown when the condition is false.

}
expect_failures?: [any*]

Checks or variables that should fail validation in this run.

module? { source: string }

Test a different module than the one in the directory, e.g. a setup helper.

}
Example
run "names_the_bucket" {
  command = plan
  assert {
    condition     = aws_s3_bucket.reports.bucket == "af-reports"
    error_message = "wrong bucket name"
  }
}

Functions

OpenTofu’s built-in functions, the common ones of ~130; usable in any expression.

Functions

Try any in tofu console.

Numeric

max(numbers:number+) -> number
max(1, 5, 3)  # 5

The largest of its arguments. Also min, ceil, floor, abs.

String

format(fmt:string, args:any*) -> string
format("af-%s-%03d", var.env, 7)

Build a string printf-style: %s, %d, %03d.

join(sep:string, items:list) -> string
join("-", ["af", var.env])

Join list items into one string with sep.

split(sep:string, text:string) -> list
split(",", "a,b")  # ["a", "b"]

Split text on sep into a list.

replace(text:string, search:string, with:string) -> string
replace(s, "/[^a-z]/", "")

Replace search in text; a "/…/" search is a regex.

trimspace(text:string) -> string
trimspace("  af  ")  # "af"

Strip surrounding whitespace. Also upper, lower, title, trim.

regex(pattern:string, text:string) -> any
can(regex("^af-", var.name))

What the pattern matches; errors on no match — wrap in can().

templatestring(template:string, vars:map) -> string
templatestring(var.tpl, { env = var.env })

Render a template you already hold as a string (1.7+).

Collection

length(value:any) -> number
length(var.cidrs)

Count items in a collection, or characters in a string.

keys(from:map) -> list
keys({ a = 1 })  # ["a"]

Keys as a sorted list.

values(from:map) -> list
values({ a = 1 })  # [1]

Values in key order.

lookup(from:map, key:string, default:any) -> any
lookup(var.ttl, "prod", 60)

Read a key, with a fallback if it is missing.

merge(maps:map*) -> map
merge(local.tags, { Env = "dev" })

Combine maps into one; later keys win.

concat(lists:list*) -> list
concat([1], [2, 3])  # [1, 2, 3]

Join lists end to end.

flatten(nested:list) -> list
flatten([[1], [2, 3]])

Unnest a list of lists.
